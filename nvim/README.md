Essa é a minha configuração pessoal do [neovim](https://neovim.io/), um editor
de texto livre de terminal. Ela requer o neovim versão 0.12, no mínimo, e
funciona melhor quando são instalados os programas `ripgrep` e `fd` (alguns
plugins os utilizam automaticamente para obter um melhor desempenho e/ou
usabilidade).

Essa configuração tem alguns anos de existência. Eu uso o neovim desde 2020, mas
reescrevi a minha configuração original do zero por volta de 2022, resultando na
que está aqui. Ao longo dos anos, fiz muitas modificações; esse histórico foi em
boa parte perdido quando migrei os arquivos para esse repositório de dotfiles
unificado, em nome de uma melhor organização.
